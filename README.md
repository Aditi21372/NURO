# NURO: AI Task Breakdown Assistant

> A Django web app that turns a vague task name into a **structured, actionable plan**: steps, tools, and resources generated by Google Gemini, with an offline fallback when the LLM is unavailable.

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=flat&logo=python&logoColor=white)
![Django](https://img.shields.io/badge/Django-092E20?style=flat&logo=django&logoColor=white)
![Google Gemini](https://img.shields.io/badge/Gemini-2.0%20Flash-4285F4?style=flat&logo=google&logoColor=white)

## What it does

You type a task, like *"Prepare for my ML midterm"*, and NURO:

1. Stores it as a `Task` (priority 1–5, deadline, completion status)
2. Sends it to **Gemini 2.0 Flash** with a structured prompt
3. Returns an ordered breakdown of specific, manageable steps plus suggested tools and techniques, returned as JSON (mindmap + checklist)
4. **Falls back** to a locally generated breakdown if the LLM call fails, so the app never dead-ends

## Task model

| Field         | Type              | Validation                        |
|---------------|-------------------|-----------------------------------|
| `title`       | `CharField(255)`  | required, non-empty               |
| `description` | `TextField`       |                                   |
| `priority`    | `IntegerField`    | must be between 1 and 5           |
| `deadline`    | `DateTimeField`   |                                   |
| `completed`   | `BooleanField`    | default `False`                   |

## Quick start

```bash
git clone https://github.com/Aditi21372/NURO.git
cd NURO/manage_tasks
python -m venv venv && source venv/bin/activate
pip install django google-genai

# add your Gemini key
export GENAI_API_KEY="your-key-here"

python manage.py migrate
python manage.py runserver
```

## LLM integration details

- Prompted for **JSON-shaped output**: logical ordering, specific and concise steps, tool/technique suggestions
- All LLM interactions are logged with a proper `logging` setup for debugging
- **Resilience first**: on any Gemini failure (network, quota, malformed response), a deterministic local breakdown keeps the user flow intact
